## 📖 About The Project

**Glow Beauty** is a single-page makeup products website that presents essential beauty products in a clean and elegant layout. It includes product cards, beauty tips, and a contact section — all designed with a soft pink and rose colour theme.

This project was created to practise:

- Semantic **HTML5** structure
- **External CSS** styling
- **Responsive layout** using Flexbox and CSS Grid
- Publishing a project on **GitHub**

---

## ✨ Features

- 🌸 Soft pink and rose colour theme
- 📱 Fully responsive (mobile, tablet, and desktop)
- 🧭 Sticky navigation bar with smooth scroll
- 💄 Six makeup product cards with prices and tags
- 🌿 Beauty tips section
- 📬 Contact form layout with labels and inputs
- ⚡ Hover effects and smooth transitions
- 🧩 Semantic HTML tags for better accessibility and SEO

---

## 🛠️ Built With

- **HTML5** — structure and semantic elements
- **CSS3** — styling, Flexbox, Grid, media queries, transitions

> No JavaScript, Bootstrap, or any framework was used. This project focuses on core web fundamentals.
